# Student Career Guidance System

## About the Project

Choosing a career can be confusing, especially when there are so many fields in technology. I built this project to make that process a little easier for students.

The Student Career Guidance System is a Java application where students can explore different career options, learn about the skills required for each field, and follow a roadmap to get started.

Currently, the application covers Web Development, Data Science, and Cyber Security. Students can also track their learning progress and save their details for future use.

## What Can You Do With It?

- Register as a student and log in.
- Choose a career domain based on your interests.
- Explore the skills required for different careers.
- View learning roadmaps for each domain.
- Check recommended projects and career information.
- Track your learning progress.
- Save and retrieve student details using file handling.

## Technologies Used

- Java
- Object-Oriented Programming
- Java Interfaces
- Java Collections
- File Handling

## Concepts I Used

While building this project, I got practical experience with several Java concepts:

- **Classes and Objects:** Used to represent students, careers, and roadmaps.
- **Inheritance:** Used to create different types of students.
- **Polymorphism:** Used to handle different implementations of common methods.
- **Abstraction:** Used interfaces to define common functionalities.
- **Encapsulation:** Used to organize and manage data within classes.
- **File Handling:** Used to store and retrieve student information.

## How to Run the Project

Make sure you have Java JDK installed on your system.

**1. Clone the repository**

```bash
git clone https://github.com/abhinaluvala4/Java.git
```

**2. Open the project folder**

```bash
cd Java
```

**3. Compile the Java files**

```bash
javac *.java
```

**4. Run the application**

```bash
java Main
```
